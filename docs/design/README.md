# Design documents

`founding-research-report.md` is the research report (November 2026) that set the project's approach: the IRS and case-law framework, why the data must be collected clean-room, the survey methodology, the schema, the edition scheme, the license stack, the site design and the roadmap. `research_notes/` holds the six source notes behind it, with citations.
