# Methodology

Each methodology version is a single Markdown file, `METHODOLOGY-<year>.<n>.md`. The year is the first tax-year edition the version may build; `n` increments through draft, comment period and final.

| Version | Status | Comment period | Builds editions |
|---|---|---|---|
| METHODOLOGY-2027.0 | Draft, open for comment | Opens when the advisory council is seated | None yet |

How to comment: open a GitHub issue labelled `methodology` with the version in the title. Every comment gets a written disposition in the adjudication table appended to the final version.

Values rows record the `method_version` that produced them, so a method change is visible per item and the prior version's values remain in the edition archive.
