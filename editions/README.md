# Editions

Frozen tax-year editions, `DV-<taxyear>[.<n>]`, one directory each. None published yet.

Each edition directory will contain the three CSV tables, `datapackage.json`, `SHA256SUMS`, `DATASHEET.md`, `CHANGELOG.md` (per-item diff against the prior edition with reason codes) and the shipped LLM response cache. Editions are never modified after publication; see `methodology/` section 10.

`REMOVALS.md` logs every takedown or personal-data removal applied to published data.
